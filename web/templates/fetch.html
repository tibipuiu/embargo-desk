Fetch new embargoes

New releases come in when someone on the team runs the fetcher on their computer. It opens EurekAlert! in a browser window, collects new embargoed releases and uploads them here; Embargo Desk then scores them and the picks appear on the board. Releases already fetched by anyone are skipped, so once a morning by one person is plenty.

1. Get your fetcher

A zip with the fetcher and your personal upload key. Keep it to yourself.

{% if has_key %}Downloading again replaces your previous key; an older copy stops working.{% endif %}

2. Set it up once

  1. Unzip it somewhere permanent, such as Documents.
  2. Windows: double-click 1 - Set up (Windows).
    Mac: right-click 1 - Set up (Mac) and choose Open.
  3. If Python isn't installed, setup opens python.org. Install it (on Windows, tick Add python.exe to PATH), then run setup again.

Setup takes a few minutes and downloads the fetcher's own copy of Chromium (about 150 MB). Your normal browser isn't touched.

3. Fetch

  1. Double-click 2 - Fetch embargoes.
  2. The first time, log in to EurekAlert! in the window that opens, with your own reporter account. It's remembered after that.
  3. Leave the window open until it says Done, usually 2–5 minutes. The progress then continues on the Runs page while Claude scores the releases.
